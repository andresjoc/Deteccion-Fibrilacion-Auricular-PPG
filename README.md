# Desarrollo de una aplicación para la detección temprana de fibrilación auricular a partir de técnicas de procesamiento digital de señales aplicado a datos de fotopletismografía (PPG)

**Profesor responsable:** Jonathan Torres  
**Grupo de investigación:** VIRTUS

---

## 📘 Descripción general

Este repositorio forma parte del proyecto **“Desarrollo de una aplicación para la detección temprana de fibrilación auricular a partir de técnicas de procesamiento digital de señales aplicado a datos de fotopletismografía (PPG)”**, dirigido por el **profesor Jonathan Torres**.

Aquí se documentan y almacenan los **avances realizados por los integrantes del grupo de investigación VIRTUS**, relacionados con la adquisición, análisis y procesamiento de señales PPG obtenidas mediante distintos tipos de relojes inteligentes.

El repositorio sirve como espacio central de trabajo, documentación y registro del progreso del proyecto.  
Conforme avance la investigación, se irán incorporando nuevos datos, pruebas, informes y desarrollos técnicos.
